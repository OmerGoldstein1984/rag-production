# Acme Corp Software Installation Guide

## Purpose
This guide provides standardized procedures for installing approved software on Acme Corp-owned devices. Following these procedures ensures compatibility, security, and proper licensing.

## Scope
This guide applies to all employees who install software on Acme Corp-issued Windows and macOS devices. It does not apply to personal devices unless used for Acme Corp work under BYOD policy.

## Approved Software List
All software must be approved by the IT Security Team before installation. The current list of approved software is maintained in the Acme Corp Software Catalog (accessible via the intranet).

### Commonly Approved Applications
- **Productivity**: Microsoft Office 365, Adobe Acrobat Reader, Slack, Zoom
- **Development**: Visual Studio Code, IntelliJ IDEA, Docker, Git
- **Design**: Adobe Creative Cloud, Figma, Sketch
- **Utilities**: 7-Zip, Notepad++, VLC Media Player

## Installation Procedures

### Windows Devices
1. **Verify Approval**: Check the Software Catalog to confirm the software is approved for installation.
2. **Download**: Obtain the installation file from the official vendor website or the Acme Corp internal software repository.
3. **Run Installer**: Execute the installer with administrative privileges.
   - Right-click the installer file and select "Run as administrator".
4. **Follow Prompts**: Accept the license agreement and choose installation options.
   - Use default settings unless specific configuration is required.
5. **Complete Installation**: Allow the installer to finish and reboot if prompted.
6. **Verify Installation**: Launch the software to ensure it functions correctly.
7. **Report**: Log the installation in the Software Tracking System (STS) within 24 hours.

### macOS Devices
1. **Verify Approval**: Check the Software Catalog to confirm the software is approved for installation.
2. **Download**: Obtain the installation file (typically .dmg or .pkg) from the official vendor website or the internal repository.
3. **Open Installer**: Double-click the downloaded file to mount the disk image or launch the package installer.
4. **Run Installer**: Follow the on-screen instructions.
   - You may be prompted to enter your administrator password.
5. **Complete Installation**: Allow the installer to finish and reboot if prompted.
6. **Verify Installation**: Launch the software to ensure it functions correctly.
7. **Report**: Log the installation in the Software Tracking System (STS) within 24 hours.

## Prohibited Practices
- Do not download software from unverified third-party websites.
- Do not install software that requires disabling security features (e.g., antivirus, firewalls).
- Do not use peer-to-peer (P2P) networks to obtain software.
- Do not share installation media or license keys without authorization from IT Licensing.

## Troubleshooting
- If installation fails, check the Windows Event Log or macOS Console for error messages.
- Ensure you have sufficient disk space and administrative privileges.
- Contact the IT Help Desk for assistance with installation issues.
- Do not attempt to modify installation files or bypass security controls.

### Abbreviations
