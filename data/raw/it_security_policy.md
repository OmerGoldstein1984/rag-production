# Acme Corp IT Security Policy

## Effective Date: January 1, 2024
## Version: 3.0

### Policy Overview
This policy outlines the security measures and procedures to protect Acme Corp's information assets, including data, systems, and networks.

### Scope
This policy applies to all employees, contractors, consultants, temporaries, and other workers at Acme Corp, including all personnel affiliated with third parties.

### Password Policy
- All user passwords must be at least 12 characters long.
- Passwords must contain a combination of uppercase letters, lowercase letters, numbers, and special characters.
- Passwords must be changed every 90 days.
- Passwords cannot be reused within the last 5 cycles.

### Multi-Factor Authentication (MFA)
- MFA is required for all remote access to Acme Corp networks.
- MFA is required for access to systems containing sensitive data (e.g., financial systems, HR databases).
- Accepted MFA methods include hardware tokens, authenticator apps, and SMS verification.

### Data Encryption
- All sensitive data stored on Acme Corp servers must be encrypted using AES-256 encryption.
- Data in transit between Acme Corp facilities and over public networks must be encrypted using TLS 1.2 or higher.
- Laptops and mobile devices must have full-disk encryption enabled.

### Network Security
- Acme Corp uses firewalls to segregate network segments and control traffic.
- Intrusion Detection Systems (IDS) monitor network traffic for malicious activity.
- Wireless networks must use WPA3 encryption and be segregated from the internal network.

### Incident Response
- All security incidents must be reported to the IT Security team within one hour of discovery.
- The IT Security team will follow the Acme Corp Incident Response Plan (IRP-001) to contain, eradicate, and recover from incidents.
- Post-incident reviews are conducted to update security measures.

### Abbreviations
- AES: Advanced Encryption Standard
- TLS: Transport Layer Security
- IDS: Intrusion Detection System
- WPA: Wi-Fi Protected Access
