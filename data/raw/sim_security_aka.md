# SIM Security and AKA Authentication

## Effective Date: January 1, 2023
## Version: 1.0
## Topic: SIM Security
## Source: 3GPP TS 43.020, TS 55.205, ETSI TS 102 221, TS 131.102
## Access Level: public

### Overview

SIM (Subscriber Identity Module) security protects the subscriber's identity and authentication credentials on a mobile network. The SIM/USIM is a secure smart card (or embedded eUICC) that stores the subscriber's secret key and runs the authentication algorithm. Mutual authentication between the UE/network and the subscriber prevents rogue base stations from impersonating the network (IMSI catching) and prevents the network from accepting fake subscribers.

### Key Concepts

- **IMSI (International Mobile Subscriber Identity):** Unique subscriber identifier stored on the SIM/USIM. Transmitted over the air only when necessary (modern networks use temporary identifiers like GUTI/5G-GUTI to avoid exposing the IMSI).
- **Ki:** The 128-bit root authentication key shared between the SIM/USIM and the AuD (Authentication Center) / HSS / UDM. Never leaves the card or the AuD.
- **AKA (Authentication and Key Agreement):** Challenge-response mutual authentication protocol. The network sends a challenge; the SIM computes a response using Ki. The network verifies it, establishing a shared cipher key.
- **Authentication Vector:** A tuple (RAND, AUTN, XRES, KASME/CK/IK) generated by the AuD. RAND is the random challenge, AUTN is the authentication token (allows the SIM to authenticate the network), XRES is the expected response, and KASME/CK/IK are derived cipher/integrity keys.

### AKA Procedure (EPS/5G)

1. The MME/AMF requests authentication vectors from the HSS/UDM via the AuD.
2. The network sends RAND and AUTN to the UE over the air (NAS Authentication Request).
3. The USIM verifies AUTN (MAC check) — if valid, the network is authenticated to the subscriber.
4. The USIM computes RES from RAND and Ki and sends it to the network (NAS Authentication Response).
5. The MME/AMF compares RES against XRES. If they match, the subscriber is authenticated.
6. Keys (KASME in EPS, K_gNB/K_n3IWF in 5G) are derived from Ki/RAND and used for NAS and AS (air interface) ciphering and integrity protection.

### Security Properties

- **Mutual authentication:** The subscriber authenticates the network (via AUTN MAC), and the network authenticates the subscriber (via RES).
- **IMSI protection:** Temporary identifiers (TMSI, P-TMSI, GUTI, 5G-GUTI) are used instead of the IMSI wherever possible, reducing IMSI-catching risk.
- **Ciphering and integrity:** NAS messages and AS (RLC/PDCP) traffic are ciphered and integrity-protected using keys derived from AKA.
- **USIM application toolkit (USAT):** Allows the SIM to initiate commands (e.g., proactive commands) and enforce issuer-specific security policies.

### Threats Mitigated

- **IMSI catchers / stingrays:** Rogue base stations that capture IMSIs by broadcasting a stronger cell signal. Mitigated by temporary identifiers and mutual authentication (a fake base station cannot produce a valid AUTN without Ki).
- **Cloning:** Copying a SIM to impersonate a subscriber. Mitigated by tamper-resistant secure storage of Ki.
- **Eavesdropping:** Mitigated by ciphering keys derived from AKA.
